Uso de los elementos <map> y <area> en HTML

Elemento <map>

El elemento <map> se utiliza para crear un mapa de imagen que contiene uno o más elementos <area>.

Debe tener un atributo name que se relaciona con el atributo usemap de una etiqueta <img>. Esto permite que la imagen se asocie con el mapa.

Ejemplo de uso:


<map name="nombreMapa">
    <area shape="rect" coords="0,0,50,50" href="link1.html" alt="link 1">
    <area shape="circle" coords="100,100,30" href="link2.html" alt="link 2">
</map>

Elemento <area>

El elemento <area> se utiliza para definir áreas específicas dentro de un mapa de imagen que son clicables y pueden redirigir a diferentes enlaces.

Atributos importantes:

  • shape: Define la forma del área (rectángulo, círculo o polígono).
  • coords: Especifica las coordenadas que definen la forma del área.
  • href: Indica la URL a la que se redirige al hacer clic en el área.
  • alt: Proporciona un texto alternativo para mejorar la accesibilidad.

Ejemplo de uso:


<area shape="rect" coords="10,10,50,50" href="link1.html" alt="link 1">
<area shape="circle" coords="100,100,30" href="link2.html" alt="link 2">

Asociación entre <img> y <map>

Para asociar una imagen con un mapa, se utiliza el atributo usemap en la etiqueta <img>. Aquí hay un ejemplo completo: 


<img src="imagen.jpg" usemap="#nombreMapa" alt="Descripción de la imagen">
<map name="nombreMapa">
    <area shape="rect" coords="0,0,50,50" href="link1.html" alt="link 1">
    <area shape="circle" coords="100,100,30" href="link2.html" alt="link 2">
</map>
