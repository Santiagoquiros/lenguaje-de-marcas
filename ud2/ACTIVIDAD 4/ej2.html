<details>

El elemento <details> se utiliza para crear un cuadro que puede ser expandido o colapsado por el usuario. Es útil para mostrar información adicional que no necesita estar visible todo el tiempo.

<summary>

El elemento <summary> se utiliza dentro de <details> para proporcionar un resumen o título que el usuario puede hacer clic para expandir o colapsar el contenido.

El elemento <mark> se utiliza para resaltar texto, indicando que es relevante o importante. Generalmente, el texto resaltado se muestra con un fondo amarillo.

<hr>

El elemento <hr> se utiliza para crear una línea horizontal que separa contenido en la página. Es útil para dividir secciones o temas diferentes.
