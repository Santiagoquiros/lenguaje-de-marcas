Atributos del Elemento <area>

El elemento <area> se utiliza dentro de un elemento <map> para definir áreas activas en una imagen. A continuación se presentan los atributos admitidos:

  • alt:

    Texto alternativo que describe el área. Se muestra si la imagen no se puede cargar.

  • coords:

    Coordenadas que definen la forma del área activa. El formato depende del valor de shape.

  • href:

    URL a la que se enlaza el área activa.

  • shape:

    Define la forma del área activa. Puede ser rect (rectángulo), circle (círculo) o poly (polígono).

  • target:

    Especifica dónde abrir el enlace (por ejemplo, en una nueva pestaña).

  • title:

    Texto que aparece como un tooltip cuando se pasa el ratón sobre el área.

  • download:

    Indica que el enlace es para descargar un recurso.

  • media:

    Especifica una consulta de medios para el enlace.

  • rel:

    Define la relación entre el documento actual y el recurso vinculado.

Ejemplo de uso

        
<area 
    alt="Texto alternativo para el área" 
    coords="x1,y1,x2,y2" 
    href="https://www.ejemplo.com" 
    shape="rect|circle|poly" 
    target="_blank|_self|_parent|_top" 
    title="Título del área" 
    download 
    media="media-query" 
    rel="noopener noreferrer">
